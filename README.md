# Neo Genesis Ventures

A minimal brand website for Neo Genesis Ventures, an investor and builder of AI and energy ventures.

## Run locally

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory to a static hosting provider.

The hero is an original Canvas 2D toroidal field with pointer interaction. It loops automatically, respects reduced-motion preferences, and stops rendering when hidden or outside the viewport. No animation library is required. Typography uses DM Sans from Google Fonts with a system fallback.

Content is in `index.html`, styling in `src/style.css`, and motion in `src/main.js`.
