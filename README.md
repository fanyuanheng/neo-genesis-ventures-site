# Neo Genesis Ventures

A minimal brand website for Neo Genesis Ventures, an investor and builder of AI and energy ventures.

## Run locally

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Deploy the generated `dist/` directory to a static hosting provider.

The hero retains its original Canvas 2D toroidal field. The vision illustration uses a separate folded ribbon: flowing ivory contours become an amber digital lattice, with light traces circulating through both worlds. Pointer movement gently shifts each view. Both share pause controls, respect reduced-motion preferences, and stop rendering when hidden or outside the viewport. No animation library is required. Typography uses DM Sans from Google Fonts with a system fallback.

Content is in `index.html`, styling in `src/style.css`, and vision motion in `src/main.js`, and the original hero motion in `src/hero-motion.js`.
